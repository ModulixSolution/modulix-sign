# Modulix Mutual NDA template

Source documents for the Mutual NDA served at https://sign.modulix.gg/mnda
(DocuSeal share link `/d/SMtDThUiczWBWu`).

Document footer version: November 2026.

These files are the template used for new signings. Already-signed records
are stored as submission documents and are not changed when this template is
updated.

## Changelog

Moved the list conjunction “or” from the end of item (3) so it now precedes item (5). Bumped the footer date from December 2025.
